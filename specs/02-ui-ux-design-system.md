# UI/UX Design System Specification

## 1. Aesthetic Direction
- **Theme**: Premium Dark Modern Fintech / Legaltech.
- **Visuals**: Deep obsidian backgrounds (`#0a0e17`), elevated card surfaces (`#121826`), subtle glowing borders, glassmorphic blurs (`backdrop-filter: blur(16px)`).
- **Typography**:
  - Headings: 'Outfit', sans-serif (clean, authoritative)
  - Body: 'Plus Jakarta Sans', sans-serif (highly legible)
  - Hashes & Proof Data: 'JetBrains Mono', monospace (cryptographic feel)

## 2. Color Palette
- **Primary / Brand**: Electric Indigo `hsl(245, 82%, 67%)`
- **Verified / Safe**: Emerald Green `hsl(158, 64%, 52%)`
- **Warning / Disputed**: Amber `hsl(38, 92%, 50%)`
- **Damage / Danger**: Rose Coral `hsl(350, 89%, 60%)`
- **Neutral Surface**: `hsl(222, 47%, 11%)`
- **Border Subtle**: `rgba(255, 255, 255, 0.08)`

## 3. Micro-Interactions
- Smooth card hover lift (`transform: translateY(-2px)`).
- Ripple/glow on primary actions.
- Animated copy confirmation for cryptographic hashes.
- Stepper progress bar for Move-in and Move-out inspections.
