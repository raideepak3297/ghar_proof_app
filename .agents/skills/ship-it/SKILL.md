# Ship It

## What to do
1. Review git status and diff.
2. Generate Conventional Commit message: `feat(scope): ...` or `fix(scope): ...`.
3. Provide clean PR summary with:
   - Summary of Changes
   - New Screens / Components
   - API Integrations
   - Manual Testing Checklist
4. Wait for explicit user confirmation to commit.
